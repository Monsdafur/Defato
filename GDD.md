# Tower Def Game

## 1. Game Overview

### 1.1 Concept
A automation resource management tower defense game

### 1.2 Genre
- Primary Genre: Tower defense
- Secondary Genre: Factory builder

---

## 2. Gameplay

### 2.1 Core Gameplay Loop
1. Build factory to automate resources
2. Use resources provided by the base to construct defense
3. Defend your base from enemy waves
4. Repeat

### 2.2 Player Mechanics
The player can fly over all obstacles and construct machines, cannot attack and can only repair and observe 

---

## 3. Game Systems

### 3.1 Tower Defense
The player will be provided with a core structure that they will have to defend from enemy waves by building defense around it

### 3.2 Automation, Factory Building
Resources are harvested from the environment via drills and extractors, then processed into higher tier resources to construct more factory and weaponry

---

## 4. World & Level Design

### 4.1 World Overview
Hand crafted maps and challenges (maybe)

### 4.2 Level Design
- Mountains: Impassible obstacles, player cannot build and enemies cannot go pass them
- Shallow water: Can help slow enemies down but player cannot build over
- Deep water: Behaves the same as mountains
